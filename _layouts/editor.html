        The editor API isn’t running

        The studio saves through a small local server on port 4001. Start everything from the repo root with:

        bin/dev

        Or start only the API (Ruby 3.3, from the repo root):

        ruby -rbundler/setup scripts/local_editor_server.rb

        Use ruby -rbundler/setup, not bundle exec ruby: the repo path has a space in it. Checking again every few seconds.
