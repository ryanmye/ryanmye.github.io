{%- comment -%} The project list: `featured: true` projects first, then the rest in projects.yml order. Each row has the title with "code →" when the project has a url, and the date right-aligned. - Homepage (default): featured rows add `short` (a one-to-two-line version for the homepage column), else the `summary`; the others add the one-line `context` (team and role). - details=true (/projects/): every row adds `summary` and `context`, then a
with the description and bullets; the list is two columns from 700px with featured rows spanning both. A project with `image` gets a .row-media picture first (the li gets .has-media), linked to `site`, else `url`. The link is aria-hidden and out of the tab order because the title row already links there, so the alt is left empty inside it (`alt` is used when there is no link). The first picture is fetchpriority=high, the rest lazy. No `image`, no picture. After the featured rows, the projects with a picture come before the ones without (each group in file order), so a grid row never pairs a picture with a text-only cell that would read as its caption.
